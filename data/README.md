Questa cartella non e piu il riferimento operativo del progetto.

Uso raccomandato:
- `runtime/data/` per database e backup runtime
- `runtime/imports/` per Excel, estratti e import manuali
- `runtime/validation/` per copie di verifica e analisi locali

Se compaiono di nuovo file in `data/`, trattali come residui locali da ricollocare in `runtime/`.
